# AetherUI Extension

Premium Chrome extension shell for the AetherUI freemium AI design intelligence product.

## What It Does

- Captures and analyzes UI sections with a polished premium shell.
- Surfaces free-tier analysis, pro-tier landing-page intelligence, and similarity workflows.
- Stores local account state, prompt history, favorites, and usage counts.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## Experience Notes

- The popup is designed as a cinematic dark, glassmorphism-heavy product UI.
- Free users can still inspect and analyze meaningfully; Pro unlocks the deeper AI workflows.
